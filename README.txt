PSW Academic Achievement Dashboard
==================================
Source of truth: ผลสัมฤทธิ์ sgs 1-2568+2569.xls
Sheets: 1-2568, 1-2569

วิธีใช้งาน
1) แตกไฟล์ ZIP
2) เปิด index.html ด้วย Chrome/Edge
3) เชื่อมต่ออินเทอร์เน็ตในครั้งที่เปิด เพื่อโหลด Chart.js, html2canvas และ jsPDF จาก CDN
4) ใช้ตัวกรองด้านบน / โหมดนำเสนอ / Export PNG / Export PDF

นิยาม KPI
- ผ่านเกณฑ์ = เกรด 1, 1.5, 2, 2.5, 3, 3.5, 4
- ไม่ผ่าน = 0, ร, มส
- Grade 3+ = 3, 3.5, 4
- GPA ใช้เกรดตัวเลข 0–4 เท่านั้น ไม่รวม ร/มส

ข้อจำกัดของไฟล์ต้นฉบับ
- ไม่มีชื่อ/เลขประจำตัวนักเรียน จึงไม่สามารถนับ Unique Student กลุ่มเสี่ยงได้
- ไม่มีห้องเรียนและครูผู้สอน จึงไม่มี Filter ห้อง/ครู
- KPI จำนวนนักเรียนใช้ยอดสูงสุดรายระดับชั้นจากคอลัมน์จำนวนนักเรียน เพื่อหลีกเลี่ยงการนับซ้ำรายวิชา
